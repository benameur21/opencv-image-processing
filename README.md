# Digital Image Processing with OpenCV

Practical work on **digital image processing** using Python and OpenCV, based on the **Lena image**.

## 🛠️ Technologies

* Python
* OpenCV
* NumPy
* Matplotlib
* scikit-image

## 📌 Topics Covered

* Image loading and properties
* RGB channels and grayscale conversion
* Resize, crop, and flip
* Gaussian and median filtering
* Canny edge detection
* Binary thresholding and Otsu
* Salt-and-pepper noise
* Noise reduction
* Morphological operations:

  * Structuring elements
  * Erosion
  * Dilation
  * Opening
  * Closing
* Comparison of image-cleaning methods
